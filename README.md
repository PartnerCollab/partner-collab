# Partner Collab — 双人协作台

专为锐（产品开发）与洋（销售开拓）打造的信息同步与项目管理工具。

## 功能模块

- **项目看板**：拖拽式管理需求进度（待确认 → 开发中 → 测试中 → 已交付）
- **头脑风暴**：记录商机灵感，支持投票评估
- **信息同步日志**：异步日志，支持日报/周报，区分作者
- **决策记录**：重要决定 + 背景原因，留存历史

## 访问地址

👉 https://partnercollab.github.io/partner-collab/

## 使用说明

1. 打开上述链接即可使用
2. 数据存储在本地浏览器（localStorage）
3. 双方各自用自己的浏览器，数据互不干扰
4. 左下角显示北京/美西双时区时钟

> ⚠️ 当前版本为本地存储版。如需数据真正共享（双方实时看到同一份数据），可升级为云同步版本。
