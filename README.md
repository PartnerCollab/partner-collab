# Partner Collab — 双人协作台

专为锐（产品开发 · 🇺🇸 美国）与洋（销售开拓 · 🇨🇳 中国）打造的信息同步与项目管理工具。

## 访问地址

👉 https://partnercollab.github.io/partner-collab/

## 功能模块

- **项目看板**：拖拽式管理需求进度（待确认 → 开发中 → 测试中 → 已交付）
- **头脑风暴**：记录商机灵感，支持投票评估
- **信息同步日志**：异步日志，支持日报/周报，区分作者
- **决策记录**：重要决定 + 背景原因，留存历史

## 技术架构

- 前端：纯 HTML/CSS/JS，单文件无需构建
- 后端：Firebase Firestore，**数据实时双向同步**
- 身份：本地选择（洋/锐），不涉及服务器认证

## 使用说明

1. 打开上述链接
2. 首次使用时选择你的身份（洋 或 锐）
3. 双方添加的内容会自动同步，实时可见
4. 左下角显示北京/美西双时区时钟

## 数据配置

如需迁移到自己的 Firebase 项目：
1. 创建 Firebase 项目：https://console.firebase.google.com/
2. 添加 Web 应用，复制配置
3. 打开 `index.html`，找到 `firebaseConfig` 对象，替换为你的配置
4. 在 Firestore Database 中创建数据库（测试模式即可）
